Lunar Courier 3D is a browser-based 3D space-survival game built with JavaScript, Three.js, HTML, CSS, and WebGL. Navigate a hazardous lunar approach, collect drifting scientific samples, dodge asteroids and solar flares, upgrade your spacecraft, and survive the ultimate Solar Storm challenge.

No download or separate frontend build is required. Three.js is loaded from a CDN, so an internet connection is needed.

---

## ✨ Key Features

- 🪐 **3D Space Environment:** Earth, the Moon, stars, and drifting cosmic dust.
- 🚀 **Animated Spacecraft:** Shader-based engine plume and boost effects.
- ☄️ **Space Hazards:** Asteroids, debris, and solar flares with warning sequences.
- 💎 **Sample Collection:** Collect canisters to complete waves and increase your score.
- ⚡ **Ship Upgrades:** Improve plating, thrusters, sample attraction, boost recharge, and rock resistance.
- 🔥 **Solar Storm:** Survive the 25-second final challenge in Wave 5.
- 🎬 **Cinematic Sequences:** Intro, victory, and mission-failure cutscenes.
- 🎮 **Multiple Controls:** Keyboard, touch-screen, and gamepad support.
- 🎨 **Customization:** Graphics settings, audio controls, reduced motion, flash reduction, colour palettes, and high-contrast mode.
- 🏆 **Replayability:** High scores, selectable difficulty, and seed-based replay.

## 🕹️ Controls

| Action | Desktop control |
|---|---|
| Move | `WASD` or arrow keys |
| Boost | `Space` or `Shift` |
| Pause / Resume | `P` or `Esc` |
| Mute / Unmute | `M` |
| Fullscreen | `F` |

Touch devices use a floating joystick and boost button. Compatible gamepads support movement, boosting, and menu navigation.

## 🛠️ Built With

- HTML5 and CSS3
- JavaScript
- Three.js r128
- WebGL and GLSL shader effects
- Canvas API for procedural textures
- Web Audio API for synthesized music and effects
- LocalStorage for saved settings and high scores

### 💻 Run Locally

Download the HTML file, rename it to `index.html`, and open it in a modern browser with WebGL support and an internet connection.

Alternatively, run a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
